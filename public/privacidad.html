Política de privacidad

Cinetracker es una web personal para llevar una lista de películas y series para ver.

Qué datos guarda. Cuando entrás con Google o con tu mail se guarda tu dirección de correo para identificar tu cuenta. Además se guarda lo que marcás en la web: qué viste, qué puntaje le pusiste y qué títulos sumaste a tu lista.

Para qué se usan. Solo para mostrarte tu lista en cualquier dispositivo. No se venden, no se comparten con terceros y no se usan para publicidad.

Dónde se guardan. En una base de datos de Supabase. Cada usuario solo puede ver y modificar sus propios datos.

Datos de películas. Afiches, sinopsis y tráilers vienen de TMDB y YouTube.
